# SyncChip

The status in the header: an icon and a word, never colour alone.

- Saved: `saved-ink` text and border with a check.
- Loading: `ink-muted` with a turning arrow.
- Active operation: `error-bg` ground, `error-ink` text, a dot and the word Active.
- Sentence case at 14px, weight 600, `radius-md`. Offline states are not designed: offline is not a requirement.
