# GradeBadge

A report's source grade: reliability A to F and credibility 1 to 6, in mono.

- `grade` style in a 1px `ink-muted` box at `radius-sm`; an unverified grade (E or F, 5 or 6) uses a dashed box.
- Always carries an `aria-label` that spells it out: "Grade B2, usually reliable, probably true".
- Spelled out in words beside it on detail screens.
