# WaveWatch: second brain

The knowledge vault for WaveWatch, a community safety OSINT and incident-coordination platform for Jeffreys Bay.

- Start with `wiki/STATE.md`, then `CLAUDE.md`.
- `wiki/index.md` is generated: run `python3 tools/wiki_build.py`.
- Check the vault: `python3 tools/wiki_lint.py` (exits non-zero on any failure).
- First-time setup (Claude Code configuration, git, GitHub, Obsidian): `wiki/runbooks/first-time-setup.md`.

This repository holds knowledge only. App code lives in `WaveWatch-App`.
