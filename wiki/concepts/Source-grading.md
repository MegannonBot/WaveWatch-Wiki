# Source grading

## Definition

Source reliability A (completely reliable) to F (cannot be judged); report credibility 1 (confirmed by another source) to 6 (cannot be judged). A report reads like "B2".

## Why it matters

A first-hand camera result outweighs a forwarded rumour; patterns should rest on graded information.

## How WaveWatch uses it

Each source has a default reliability; each report starts with it and can be changed. AI extraction maps confidence high, medium, low to 2, 3, 4.

## Sources

Standard intelligence grading (the A to F and 1 to 6 scale); applied in the artifact.
