# Near-repeat

## Definition

Two or more break-ins (or vehicle crimes) within a set distance and number of days of each other. Default 400 m and 14 days, editable.

## Why it matters

Burglars often return to the same few streets within days; warning neighbours and patrolling there is the practical response.

## How WaveWatch uses it

Alerts in Insights, a toast when a new incident is a near-repeat, and a factor in patrol zones.

## Sources

Research on repeat and near-repeat victimisation (for example https://www.emerald.com/insight/content/doi/10.1108/PIJPSM-12-2016-0172/full/html, abstract only); the strength of the effect varies by area.
