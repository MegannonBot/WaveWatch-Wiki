# Run the WaveWatch demo

## When to use

Showing WaveWatch to the coordinator or anyone else.

## Steps

1. In the artifact's Share menu, turn off "Anyone with the link".
2. Invite the person by email with **Can edit** (view-only shows no data).
3. More, Data, remove demo data if an older demo is loaded, then Load demo data (about 150 records).
4. Walk: Map (layers, replay), Log (reports feed), Cases (Pellsrus case: route, gaps, exit routes), Ops (search and collision), Ops, Patrol planner, Insights (Patterns, Briefs, SAPS stats).
5. Run the AI parts (Import, Ask, AI brief) from Franco's account.
6. Afterwards remove the demo data before real use.

## Checks

The label top right reads "Private, saved".

## If it goes wrong

"Read-only": the invite is not Can edit. No data: the link is still public, or the person is a viewer.
